Aplicativo Android desenvolvido como TCC do curso de Sistemas de Informação do IFPR — Campus Palmas, para gerenciamento de agendamentos em barbearias.

Tecnologias

Java, Android Studio, XML, Retrofit, PostgreSQL e Supabase.

Como executar

Baixe ou clone o projeto:
git clone https://github.com/JulioVerginaci/BarberOrganizer.git

Abra a pasta no Android Studio.

Aguarde a sincronização do Gradle.

Selecione um emulador ou celular com Android 10 ou superior.

Clique em Run ▶ para executar.

Observação: é necessário acesso à internet e ao Supabase configurado no projeto.
